One host-neutral runtime now serves both Hosts: `plugins/immune-brain/runtime/host-core/runtime.ts` holds `HostRuntime`, the body the Claude Code and Antigravity runtimes previously shared by inheritance, and each adapter composes an instance with its own `HostRuntimeProfile` (host id, native confirmation reference, `AssuranceHostPort` and its `observe`, probe, Lane relay factory, Lane parent check). `AntigravityRuntime extends ClaudeRuntime` is gone, so `plugins/immune-brain/runtime/antigravity/kernel_ports.ts` no longer imports the Claude runtime and the host-to-host baseline in `tests/runtime-layering-boundary.test.ts` shrinks to its last edge (`antigravity/mcp_server -> claude/mcp_server`, retired by S4). `NativeAuthorityError` is declared once in `runtime/host-core/interaction.ts`; both adapters re-export or import it, and each runtime composition names its own confirmation reference (`claude-*` for the Claude profile, `antigravity-*` for the Antigravity profile; the Antigravity MCP entrypoint still composes the Claude profile until S4 moves it onto the shared MCP runtime). Public adapter method names, tool behavior and Kernel outcomes are unchanged. Known follow-up outside this Slice's scope: `.imm/risk-floor.json` still floors `runtime/claude/kernel_ports.ts` (now the adapter facade) rather than `runtime/host-core/runtime.ts`. No user-visible change (#414).
