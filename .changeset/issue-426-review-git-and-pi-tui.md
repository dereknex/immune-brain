The `authority-review` skill and both role prompts tell the role to run one git command at a time from the current working directory, with no `-C`, pipes or redirection. Outside Herdr a Pi Executor is no longer spawned as `pi --print`, which can never settle: the runtime reports `lane_executor_requires_tui`, keeps the single-task child enrolled with its `executor` handoff, and asks the user to run `/skill:drive <task_id>` in interactive pi in the Lane before calling `start_unattended_batch` again.
