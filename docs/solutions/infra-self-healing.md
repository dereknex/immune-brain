# Pattern: 自愈式架构约束 (Self-healing Constraint Checks)

**领域**: 系统工程 / 质量保证  
**描述**: 引入主动扫描机制，确保开发环境始终符合预定义的系统宪法或架构规约。

## 场景
- 复杂 Agentic 系统初始化后。
- 长期运行后，手动操作可能导致的目录或文件漂移。

## 方案模板
1. **定义约束列表**: 明确系统运行所需的最小物理集合（目录、文件、指令）。
2. **扫描与验证**: 编写工具（如 `imm-heal`）定期遍历环境，对比实际状态与预期约束。
3. **修复建议引导**: 扫描失败时不仅要报错，还必须提供具体的修复指令（如 `mkdir`, `touch`）。

## 约束与建议
- **低成本**: 扫描器应极速运行，不影响正常开发。
- **高可见性**: 使用直观的分数或符号系统，让健康状况一目了然。
