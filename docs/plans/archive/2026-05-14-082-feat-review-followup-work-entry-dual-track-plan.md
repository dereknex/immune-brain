# Iteration Plan: Review Follow-up Dual-Track Work Entry

## Task

- Summary: Implement the Dual-Track execution model in Immune-Brain to decouple the source of execution for `imm-work` into Plan and Follow-up
- Origin: imm-brainstorm -> imm-planner
- Spec: `.imm/specs/review-followup-work-entry-dual-track.spec.md`

## Research

- `skills/imm-work/SKILL.md` currently expects a validated plan step
- `skills/imm-code-review/SKILL.md` output a `follow_up` handoff
- `skills/imm-ui-review/SKILL.md` output a `follow_up` handoff
- The tension between Planner authority and fast follow-up execution requires a conceptual separation of the artifacts driving execution

## Decisions

- D1: Treat `follow_up` from review stages as a first-class execution artifact parallel to a Plan step
- D2: Update `imm-work` to accept either a validated Plan step or a pending `follow_up` handoff
- D3: Relieve `imm-planner` of processing minor `follow_up` artifacts focusing it purely on Plans

## Assumptions

- The `follow_up` artifact generated by reviewers contains enough structural information to allow `imm-work` to execute
