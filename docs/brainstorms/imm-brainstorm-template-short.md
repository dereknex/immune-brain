# imm-brainstorm（简版）

默认写成一段短 handoff，不要像表单逐项填写。

- 结论：先用 1-2 句说清楚真正要解决的问题。
- 范围：一句话写明这次做什么、不做什么。
- 关键判断：只保留会影响下一步的 2-3 条结论。
- 假设 / 风险：只写最高信号项，没有就省略。
- 下一步：写 `Next Action`、推荐下一 skill、是否需要用户确认。

只有在边界容易误解、任务阻塞、或需要强提醒路由时，才补充：

- Allowed
- Blocked
- Workflow guard
